# Artifacts

Public-safe governance artifacts are organized by evidence type. Only sanitized, original, or appropriately licensed material belongs here.

- `ai-inventory/` — inventory and ownership examples
- `risk-assessment/` — risk methods and anonymized findings
- `model-card/` — model and system documentation examples
- `incident-response/` — incident lifecycle and response artifacts
- `governance-controls/` — control mappings and evidence requirements

Participant-specific reports, confidential client records, credentials, and proprietary implementation materials are excluded.
