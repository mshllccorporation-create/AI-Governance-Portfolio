# Data and Model Governance for AI Enabled Operations

## Academic context

Independent academic assignment completed as part of postgraduate study in artificial intelligence for business. Grade: 65.

## Problem

Organizations using customer-service, CRM, forecasting, and behavioral models must manage data quality, labeling, lineage, bias, interpretability, security, and human oversight at the same time.

## Approach

The assignment considered supervised learning, model validation, fairness testing, explainability, drift monitoring, data governance, vendor dependencies, and security risks such as data poisoning and prompt injection.

## Use cases

- Data-readiness and lineage assessment
- Fairness and bias review
- Model monitoring and drift response
- Human-in-the-loop decision controls
- Vendor and interoperability risk assessment
- Customer-service and predictive analytics governance

## Practical lesson

Model performance alone is not enough. A usable governance process must connect data quality, model behavior, human decisions, security controls, regulatory expectations, and business outcomes.

## Limitations

This is an academic analysis, not a production deployment or independent audit. It uses generalized organizational examples and should not be read as a statement about any named company.
